# TaskFlow — учебная практика Vue 3

Это **стартовая заготовка, не готовое решение**. В ней специально не реализованы поиск, сортировка, CRUD, тема, события, Pinia и другие функции. В списке сейчас отображаются только первые две задачи — ученики заменяют вывод на `v-for`.

## Запуск

1. Установите Node.js совместимой версии (желательно современную LTS).
2. Откройте эту папку в VS Code / Rider и выполните:

```bash
npm install
npm run dev
```

3. Откройте адрес, который напечатает Vite.
4. Для проверки перед сдачей: `npm run build`.

## Структураe vtyz 

- `src/App.vue` — родительский компонент, в котором сейчас хранятся данные.
- `src/components/TaskList.vue` — заготовка списка.
- `src/components/TaskCard.vue` — заготовка карточки задачи.
- `src/components/BasePanel.vue` — заготовка универсальной панели для слотов.
- `src/data/seedTasks.js` — начальные задания команды и сотрудники.
- `src/main.js` — точка входа; Pinia уже подключена.
- `src/style.css` — базовый стиль.

## Правила практики

- Не переписывайте весь проект в один `App.vue`. Создавайте компоненты по заданию.
- Не изменяйте `props` напрямую в дочерних компонентах. Используйте события для запросов на изменение данных родителя.
- Не вызывайте `.sort()` на исходном массиве, если нужна вычисляемая сортировка: копируйте массив.
- Используйте устойчивые уникальные `:key` при `v-for`.
- Миксины — отдельный учебный опыт; основной проект строится на Composition API.
- Не забудьте README с инструкцией запуска и ссылку на Git-репозиторий.
