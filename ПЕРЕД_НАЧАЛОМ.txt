TASKFLOW — УЧЕБНЫЙ ПРОЕКТ VUE 3

1. Распакуйте папку starter и откройте её в VS Code / Rider.
2. Запустите npm install, затем npm run dev.
3. Выполняйте задания из интерактивного HTML (поставляется отдельно).
4. На каждом этапе делайте Git-коммиты.
5. Сдайте преподавателю ссылку на Git-репозиторий.

Важно: это не готовое решение. Некоторые функции и целые компоненты предстоит создать самостоятельно.
